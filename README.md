# Joseph2xy

I'm Joseph, a software engineer working across the stack in fintech. At work, I help turn complex financial and derivatives workflows into usable software. Outside work, I build things for gaming communities and whatever else catches my interest. Sometimes useful. Occasionally sensible.

## Things I'm building

### Momoi

*Letting the community decide what plays next. Democracy, with playlists.*

Built for a Twitch channel that runs VODs, so the community could vote on what to watch next instead of leaving it random. The winning choice plays automatically. Actively used by the community.

### PoorBot

*Too lazy to check by myself*

Built for a friend and me to get Discord alerts when game prices drop, instead of checking manually. Actively used.

### Momoi TTS

*Giving fictional characters a voice, and viewers questionable things to ask them.*

A project for creating characters with their own personalities and voices, with Twitch as a possible home for them. Still a work in progress, with more development and testing needed.
